Algorithm Comparison: Searching for a Number in a Sorted List

Correctness
Algorithm A (Linear Search): Correct. It checks each number one by one from the start until it finds the answer or reaches the end.

Algorithm B: A bit harder to understand because of low and high points, but still easy enough to follow.
